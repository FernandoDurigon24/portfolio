Sobre mi

¡Hola! Soy Luis Fernando Durigon, estudiante de Ingeniería en Sistemas de Información y desarrollador de software con un fuerte interés por crear soluciones que resuelvan problemas reales.

Disfruto desarrollar aplicaciones web modernas, escalables y fáciles de usar, participando tanto en el diseño de la interfaz como en la lógica del sistema. Me apasiona aprender nuevas tecnologías, mejorar continuamente mis habilidades y enfrentar desafíos que me permitan crecer profesionalmente.

A lo largo de mi formación he trabajado con tecnologías como PHP, JavaScript, Python, MySQL, HTML, CSS, Bootstrap, Tailwind CSS, React y Git, desarrollando proyectos que abarcan desde sistemas de gestión hasta aplicaciones orientadas a pequeños y medianos comercios.

Uno de mis principales proyectos es Simplegestion.click, un sistema de punto de venta desarrollado desde cero, donde apliqué conocimientos de desarrollo web, bases de datos, experiencia de usuario y arquitectura de software para construir una solución completa.

Me considero una persona responsable, autodidacta y orientada a resultados. Siempre busco escribir código limpio, seguir buenas prácticas y aprender de cada proyecto en el que participo.

Actualmente continúo ampliando mis conocimientos en desarrollo de software y nuevas tecnologías, con el objetivo de crecer como desarrollador y formar parte de equipos donde pueda aportar valor, seguir aprendiendo y construir productos de calidad.

Mis proyectos

Sistema POS

Simplegestion.click es un sistema de punto de venta (POS) desarrollado para ayudar a pequeños y medianos comercios a gestionar sus operaciones diarias de manera simple y eficiente. Entre sus funcionalidades se encuentran la administración de ventas, control de stock, gestión de clientes, proveedores, ingresos y egresos, impresión de tickets y reportes. El proyecto fue desarrollado íntegramente por mí utilizando PHP y MySQL en el backend, y HTML5, Bootstrap, JavaScript y jQuery en el frontend.

Tecnologías: PHP MySQL HTML5 Bootstrap JavaScript jQuery

e-commerce autoadministrable

Lemmobile es un sitio web de comercio electrónico desarrollado para una empresa de Córdoba dedicada a la venta de muebles. La plataforma permite administrar de forma sencilla el catálogo de productos, categorías, imágenes y contenido del sitio mediante un panel de administración, facilitando la gestión diaria del negocio sin necesidad de conocimientos técnicos. El proyecto fue desarrollado íntegramente por mí utilizando PHP y MySQL en el backend, y HTML5, CSS3, Bootstrap, JavaScript y jQuery en el frontend, priorizando una interfaz moderna, responsive y una experiencia de navegación intuitiva para los clientes.

Tecnologías: PHP MySQL HTML5 Css3 JavaScript
